# Capturas das duas direções

Capturas diretas do Chromium, JPEG com qualidade 90, sem retoque. Os PNGs originais estão no artefato da [execução de prévias #3](https://github.com/mauricioforteneto/oraculo-musical/actions/runs/41054791423).

Os títulos, artistas e notas são fictícios. As fotografias licenciadas abaixo são capas demonstrativas, substituíveis pelas capas reais. A revisão independente Hallmark aprovou ambas as propostas para comparação, sem achados objetivos.

As licenças indicadas continuam aplicáveis a cada fotografia. Código e identidade da interface pertencem ao projeto; as imagens são apresentadas como parte da comparação visual.

As fontes exibidas são Bricolage Grotesque, Source Serif 4, Instrument Sans e Figtree, obtidas via Google Fonts; arquivos de fonte não são redistribuídos aqui.
